# Surya Gautam — Resume and Bio-data Website

A responsive, multi-page personal website built with HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home page
- `resume.html` — Resume, education, skills, projects, and learning goals
- `biodata.html` — Bio-data / personal and educational profile
- `style.css` — Responsive dark-theme styling and print styles
- `script.js` — Mobile navigation and automatic footer year

## Run locally
Open `index.html` in your browser. No build tools are required.

## Publish using GitHub Pages
1. Create a **public** GitHub repository named `resume-biodata-website`.
2. Upload all files in this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes. GitHub Pages will display your published URL.

## Personalize before publishing
- Replace `your-email@example.com` with your email.
- Replace the GitHub and LinkedIn links with your profile URLs.
- Update project descriptions and list the actual technologies used.
- Add additional personal details only if necessary. Avoid publishing private information such as home address, phone number, date of birth, or family details on a public site.

## Print / PDF
Open `resume.html` or `biodata.html` and select **Print / Save as PDF**. Print styles hide navigation and buttons.
